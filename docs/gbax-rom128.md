# GBAX ROM128 — phase 7A

A marked GBAX cartridge larger than 32 MiB and at most 128 MiB receives a linear read-only **data** window at 0x48000000..0x4FFFFFFF, file offset = guest address - 0x48000000. First 32 MiB also remain in native ROM windows for instructions, old pointers, GPIO and compatibility. Missing bytes read zero (no mirroring). Tail (up to 96 MiB) is allocated once on load; native first 32 MiB remains mapped normally. This increases host memory use and load time. CPU scalar and multiple data reads, debugger reads, DMA3 source supported; no execution in new window, writes ignored, DMA destination rejected. ROM patches in emulator are disabled for ROM128; build/patch offline. Full file CRC32 identifies exact ROM contents for SAVX and named states. Marked >128 MiB files are rejected; legacy cartridges retain existing mapping and mapper behavior. FIXED_ROM_BUFFER builds reject ROM128. Native tests generate an original sparse 128 MiB cart and check boundary reads, read-only semantics, DMA, reset and tail identity. Native and Android builds must pass before use; no physical Android verification or game linker/SDK integration yet. Keep executable code and conventional data below 32 MiB; assets can be linked separately with explicit extended addresses. The future SDK must allocate and validate the asset table and convert pointers. No ordinary ROM changes, no Unholy modifications.
