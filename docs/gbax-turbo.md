# GBAX compute turbo — phase 6A

Opt-in marked GBAX ROMs only. Native core config gbax.cpuMultiplier = 1, 2, 4 or 8, applied at core reset (default 1, invalid values fall back to 1). Unload restores native mode. This is an experimental compute-only multiplier for selected register ALU and branch instructions executing wholly in IWRAM. It is NOT a global hardware clock change or a claim of 2/4/8x whole-game performance. ROM/BIOS/EWRAM code and data loads/stores, HLE calls, MMIO, DMA, IRQ, timers, video and audio retain normal timing. Fractional master ticks are accumulated in eighths; timing changes and halt transitions bypass scaling. GBAX named snapshots save multiplier and fraction in reserved native bytes with a private tag; old snapshots default to 1x. No raw state API or netplay support.

Regression runs ARM and Thumb IWRAM register loops for one frame at each multiplier and checks native timer ticks against 1x. Future work: benchmark ROM workloads and extend instruction timing deliberately; Android UI selector, actual device performance and audio/video QA pending. For Unholy, first identify compute kernels that can safely fit in IWRAM; no automatic relocation is performed.
